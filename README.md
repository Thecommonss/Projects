# Projects
This repository contains arrays of projects either ongoing or finished, albeit; Programming and CAD.

**Programming**

Projectile_Simulator.py
- Can Calculate Projectile Trajectory with or without variable starting height, Using Matplotlib, numpy and math libraries
  can graph the whole trajectory and also output and marked the highest point.

Material_database.py
- Uses csv and matplotlib and mainly dictionaries to save data of a input material properties and can also compare material properties.

Beam_Deflection_Calculator.py
- Using matplotlib and numpy, we can graph the beam deflection bending or in static motion with varied input force, beam width/length/height.

Password door lock
- An arduino prototype, can save password and determine if it is correct as the input password or not (will sound the piezo buzzer if password is incorrect).

Temperature monitor with PMW LED
- Also an arduino project it can monitor measured temperature and output an led signal with intensity as the measured temp. controlled by PMW pin.


**CAD**

Screw Driven Scissor Lift
- A simple Screw Driven Scissor Lift with model parts that can be opened in solidworks. Comes with full assembly file and an PDF Drawing of the assembly along with the bill of materials
